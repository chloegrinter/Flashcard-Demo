# Flashcard Demo

A flashcard application built using **Godot 4** and **SQLite**.

## Features

- Create and manage revision topics.
- Add questions and answers to topics.
- Randomised revision questions.
- Compare submitted answers with the correct answers.
- Store flashcards locally using SQLite.

## Built With

- [Godot Engine](https://godotengine.org/)
- GDScript
- SQLite
- [Godot SQLite Plugin](https://github.com/2shady4u/godot-sqlite)

## Installation
##Downloads

### Available Platforms
- Linux
- Windows
- macOS

[Manual]
1. Clone this repository:
   ```bash
   git clone https://github.com/chloegrinter/Flashcard-Demo.git
   ```
2. Open Godot.
3. Import the project by selecting its `project.godot` file.
4. Run the project.
